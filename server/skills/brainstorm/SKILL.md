# 头脑风暴

用标签表示方案的状态：`idea`（待选方案）、`picked`（用户选中的）。用户会在白板上给喜欢的方案手动加 `picked`。

## 流程

1. **明确主题**：主题不清楚时，用 ask_user 问一次（目标、约束、不要什么），最多一轮。
2. **发散**：新建一个主题节点写明问题，下面挂 5~8 个方案子节点，标签 `idea`。
   - 每个方案一个节点：标题是方案名，摘要一句话讲核心思路，正文写做法、好处、代价。
   - 方案之间要有真正的差异（不同思路，而不是同一思路的变体），可以包含一两个出人意料的。
   - 这一步只发散，不评价、不排序。
3. **请用户挑选**：发散完成后停下来，请用户在白板上给喜欢的方案加上 `picked` 标签（右键 → 标签…，可多选），选好后回复你；也可以用 ask_user 让用户直接选。不要替用户选。
4. **收敛**：先用 `canvas_list` 传 `tag=picked` 看用户选了哪些，只围绕它们继续：
   - 对每个选中方案补充细节：具体步骤、风险、所需资源，写成它的子节点。
   - 选中了多个时，新建一个「对比」节点，列出它们在关键维度上的差异；方案间有关系的用 canvas_link 连起来。
   - 没选中的方案保留在白板上，不要删除，也不要给它们加 `picked`。
5. **推荐**：最后给出你的推荐和理由（写进「对比」或「结论」节点），但决定权在用户。

## 注意

- 用户再次要求更多想法时，回到发散步骤，新方案挂在同一主题下，标签 `idea`，避免与已有方案重复。
- 用户说「合并 A 和 B」「在 C 基础上改」时，新建节点，并用 canvas_link 标明来源。
